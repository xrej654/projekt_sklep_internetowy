Do bazy danych użyto program XAMPP, baza danych jest zawarta w projekcie ale aby sprawdzić wyświetlanie danych trzeba zainstlowac program xampp, w nim odpalić apache i mySQL. Potem wejsc na strone: 
http://localhost/phpmyadmin/index.php?lang=pl, utworzyc baze danych o nazwie: "sklep internetowy" i zaimportowac baze z pliku .sql. 

Kod sklepu trzeba przenieść do folderu xampp/htdocs aby program działał poprawnie.

Strona znajduje się pod linkiem localhost/nazwa_folderu_w_ktorym_jest_kod ,np. localhost/sklep_internetowy.
